# DEEP FIN 🦈
เกมฉลาม arcade 2D ต้นฉบับ เขียนด้วย HTML/CSS/JavaScript ล้วน (ไม่ใช้ไลบรารีภายนอก) กราฟิกวาดด้วย Canvas ทั้งหมด

## โครงสร้างโปรเจกต์
- `index.html` – หน้าเกม
- `css/style.css` – สไตล์ HUD และเมนู
- `js/game.js` – ลอจิกเกมทั้งหมด
- `manifest.json`, `sw.js`, `icon-*.png` – PWA / ออฟไลน์

## วิธีเล่น
ลากนิ้ว (หรือเมาส์/WASD) เพื่อว่าย, ปุ่ม ⚡ (Space/Shift) เพื่อ boost กินสิ่งที่เล็กกว่าเพื่อโต หลบทุ่นระเบิดและนักล่า
